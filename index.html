🧪 Языки научного программирования: Python, Julia, R и MATLAB
11 апреля 2025

Научное программирование — это не только про алгоритмы, но и про производительность, визуализацию и воспроизводимость. Сегодня активно используются:

  • Python + NumPy/SciPy/Pandas — стандарт для data science и прототипирования.
  • Julia — сочетает скорость C и простоту Python, идеален для математических вычислений.
  • R — незаменим для статистики и биоинформатики.
  • MATLAB — классика инженерных расчётов (хотя всё чаще уступает Python).
  • C++ с библиотеками (Eigen, Armadillo) — когда нужна максимальная производительность.

В контексте ОС знание Python/C++ помогает писать системные утилиты и анализировать производительность. Планирую изучить Rust для безопасного системного программирования.
